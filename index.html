This page is a demonstration of design dna, a skill I built for Claude. Its job is to stop it building the website it builds for everybody else. You are standing in that website right now.

scroll to begin

01 / the problem

The average is not a style anyone picked.

A hero, three cards, a call to action, a footer rule. It is the middle of everything a model was trained on, so it arrives by reflex, and it arrives identical for every client who asks.

01 / the problem

Nothing in this room was chosen.

That is the actual failure. A default is not a mistake, it is a decision nobody made, shipped to a client with their name on it. Everything after this is the skill refusing to let that happen.

02 / what it does first

registry absolute hard off

It refuses before it designs.

The skill carries a written registry of every signal that reads as machine made, and checks the work against all of it before a line of code exists. This wall is that registry. It only ever grows.

02 / why the black bars

Most of it is closed on purpose.

A few cards are open because those tells are already common knowledge. The rest stay shut for one reason: a list you can read is a list you can design around, and the worth of this is in the enforcing, not in the knowing. Ask for the skill and you get every card.

02 / three tiers

The tier decides what can bend.

ABSOLUTE holds against everyone, including the person paying. HARD lifts only for a written reason, and the reason is kept. OFF is a default you may choose against, as long as the choice goes on the record.

03 / why this happens

why_models_converge plain_is_also_a_fail

A model is built to give the likeliest answer.

And the likeliest website is the average of every website it was shown. That is not a fault in the model, it is the model working correctly. It is simply useless if you wanted something of your own.

03 / the second trap

Removing the tells is not enough.

Strip them all out and you are left with something plain, and plain fails just as badly as generic. Most advice about avoiding the AI look walks straight into that and stops there.

03 / the second trap

So the skill sets its default to ambitious.

Not safe, not minimal by reflex. Boring is written down as a bug on the same page as the ban list, so the fix for a tell can never be to make the work quieter.

04 / the refusal pass

refusal_pass runs_twice click_to_try

This is what the registry catches.

Every panel here is a page that would otherwise have shipped. The skill runs this pass twice on every build: once before any design starts, and again on the finished work before anyone sees it.

04 / the refusal pass

Refusing is something you do, not something you have.

A list is worth nothing unless something acts on it every time, without being asked. Try one yourself and it stays refused for as long as you are here.

click any panel to refuse it, or press Rtap any panel to refuse it

04 / the refusal pass

Refuse nothing and the defaults ship.

That is not a threat, it is just what happens next. Somebody has to say no to this, in writing, on every build, or the average goes out with your client's name on it.

05 / the other half

direction.md 18_files written_first

Refusing is only half of the skill.

The other half decides. Before anything is drawn it writes a direction: the concept, the face, the palette, the bones, and the one moment worth building properly. Code is not allowed to start until that document exists.

05 / the other half

Eighteen files. Three tiers. Every axis on the record.

The ground, the face, the bones, the motion, the signature, the voice. Each one is a decision somebody has to make and write down, with a reason, before it can be built.

05 / the other half

Locking one option refuses all the others.

That is what a decision actually costs, and it is why the written record matters more than any single rule. You can watch the instrument turning. You cannot see what it settled on.

06 / before deciding

reference_study decided_not_default

It goes and looks at real work first.

The skill opens live sites and studies them before it designs anything, because you cannot design from your own taste when your taste is the average. What it takes away is the thinking, never the pixels.

06 / decided or default

Below the line it is a default. Above it, somebody decided.

Same object, both times. Structure, rhythm, weight and temperature each get named and written down before anything is drawn. That naming is the entire difference you are looking at.

06 / decided or default

A default is somebody else's decision wearing your client's name.

There is no third state. Work is either decided or inherited, and nothing is allowed to ship from underneath the line.

drag the line of heattap high or low to move the line

08 / the ledger

ledger one_row_per_build never_backfilled

Every finished build gets logged.

Not the work, the axes that make a look: the ground, the face, the bones, the motion, the signature. One row per build, written at the end of it.

08 / the ledger

The next build reads it and is barred from that ground.

This is the part that stops a studio developing a house style by accident. Repetition is not discouraged here. It is unavailable, because those axes are already spent.

08 / the ledger

It started empty and it was never backfilled.

Nothing was imported to make the record look deep. A borrowed face is the fastest way to look machine made, and the easiest face to borrow is your own from last time.

09 / the gate

the_gate render_and_measure no_fake_proof

Nothing ships unlooked at.

The skill renders the finished page, screenshots it at desktop and phone width, measures every contrast ratio against the floor, and refuses to call anything done from reading the code alone.

09 / the gate

And it never fakes the proof.

No invented statistics, no testimonials nobody gave, no client logos that were never clients. An honest gap where a number would go beats a convincing lie, every time.
